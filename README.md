# EventEase

Application mobile React Native réalisée avec Expo.

## Stack

- React Native
- Expo
- TypeScript
- React Navigation
- AsyncStorage

## Fonctionnalités prévues

- Authentification locale simplifiée
- Gestion CRUD des événements
- Participation aux événements
- Persistance locale
- Calendrier
- Géolocalisation et distance
- Informations météo
